检查器是 Termio 用来处理终端*周边*一切的侧面板：文件、更改和搜索。它就在会话旁边，
让你不必切换应用也能看代码。

每个面板读的都是当前选中会话所在那台机器上的项目。指向一个跑在 VPS 上的会话，文件树、
搜索和差异就都是那台机器的——通过 Termio server 读取，而不是把东西拷回本地。

## 文件

文件树映射工作目录。单击文件会在内置编辑器里打开，带语法高亮、软换行和实时的行列显示。
编辑自动保存——没有保存按钮，而且从另一台机器读出来的文件会写回那台机器。图片、PDF 和
HTML 则用「快速查看」预览。

### 编辑

这是一个真正的编辑器，不是查看器：

- **查找与替换**，用 Mac 的查找键：`⌘F`、`⌘G`、`⇧⌘G`、`⌘E`，以及替换和全部替换。
- **注释整行**，以及把一行或一段选区**上下移动**或**复制**。
- **Tab** 缩进整块，**回车**保持你当前所在的缩进，代码背后画有缩进参考线。
- 光标所在单词的其他出现处会被淡淡地刷上一层底色，不用搜索也能看出一个名字用在哪儿。

## 更改

git 面板有三个只读标签：

- **更改** —— 当前的差异，以清晰的统一视图渲染。
- **对比** —— 当前分支相对它将要合入的分支：一个 PR 会带过去的文件和提交，从合并基点
  算差异，所以列表和平台上看到的一致。
- **历史** —— 最近的提交，带作者头像、可展开的文件列表和逐个提交的差异。

## 搜索 [#search]

检查器的 **搜索** 标签在整个项目里做内容搜索（底层是 `git grep`），并把你直接带到匹配的
那一行。它搜的是文件内部，不只是文件名。这就是你在编辑器里熟悉的「在文件中查找」。

结果以摘录呈现，并在匹配命中的位置着色，所以你不用挨个打开就知道要的是哪一条。搜索也
跟着会话走：另一台机器上的检出就在那台机器上搜，那个会话里的 `cd` 会把搜索范围一起带过去。

## 从终端里打开文件

在终端输出里按住 Cmd 点击文件路径——即使在 Agent 的 TUI 里也行——Termio 会在编辑器里打开它。
Cmd 点击网址会用浏览器打开，`file://` 链接则打开一个只读预览浮层。
